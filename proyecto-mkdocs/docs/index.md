# Bienvenido a Mi Proyecto de Documentación

Este sitio ha sido creado con **MkDocs** para centralizar toda la información de nuestro proyecto.

## Contenido

- 📖 [Inicio](index.md): Página principal con la introducción.
- ℹ️ [Acerca de](about.md): Información sobre el proyecto, objetivos y autores.

## Cómo usar la documentación

Puedes navegar por las secciones desde la barra superior.  
Si necesitas modificar o ampliar la documentación, edita los archivos Markdown en la carpeta `docs/`.

## Estructura del Proyecto

```text
mkdocs.yml    # Archivo de configuración del sitio.

    index.md  # Página de inicio de la documentación.
